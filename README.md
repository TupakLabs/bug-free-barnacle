# Bug-Free Barnacle

Bug-Free Barnacle is a lightweight shell script that calculates simple interest based on user input. It's designed to demonstrate clean coding practices and GitHub collaboration workflows for beginners.

## Features

- Simple interest calculation via shell script
- User prompts for input values
- Clean and easy-to-read code and cool
- Fully open-source (Apache 2.0)

## Usage

Run the script in your terminal:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
